# 서울시 성동구 음식점 폐업 위험 분석 — 경쟁 네트워크와 생존분석

공개 인허가 좌표만으로 점포별 **경쟁 네트워크**를 구축하고, 2021-04-01에 영업 중이던 성동구 음식점 3,775곳이 2026-09-12까지 폐업하는지를 추적하는 **생존분석(Cox)** 저장소입니다. 최종 목표는 추정한 위험비를 System Dynamics(SD) 모형의 폐업률로 연결해 정책 시나리오를 비교하는 것입니다(SD 단계는 이 저장소에 포함되지 않음).

> 비공개 작업용 저장소입니다. 점포 상호·주소와 리뷰 요약값이 들어 있으니 공개하기 전에 맨 아래 "공개 전 점검"을 보세요. 분석 결과는 탐색적입니다.

## 연구 설계
- **분석 단위:** 점포 1개 (기준일 2021-04-01 영업 중 + 좌표 보유 3,775곳, 면적 결측 8곳 제외 시 3,767곳)
- **설계:** 기준일 한 시점의 스냅샷 + 이후 추적(설명 변수는 기준일 값)
- **결과 변수:** 기준일부터 폐업까지의 일수(`duration_days`)와 폐업 여부(`event`; 폐업 1,656곳 43.9%, 관측 종료까지 영업 2,119곳은 중도절단)
- **설명 변수:** 업력, 면적, 임대료(통제), 반경 내 동종 경쟁 수·인접 음식점 수·업종 다양성, 네트워크 구조 지표

## 재현 방법
```bash
pip install -r requirements.txt
python scripts/run_all.py
```
- 약 2분이 걸리고, 실행 후 이전 산출물과 MD5를 비교해 같은 결과인지 알려 줍니다.
- 지오코딩은 `data/raw/geocode_cache.jsonl`의 저장된 응답을 사용하므로 외부 API 호출과 키가 필요 없습니다. 새 주소를 조회하려면 환경변수 `GEOCODE_API_KEY`(VWorld)를 설정하세요.

## 알려진 한계
- **생존자 코호트:** 기준일에 영업 중이던 점포만 포함.
- **리뷰는 생존모형에 쓸 수 없음:** 폐업 점포에는 리뷰가 없어 넣으면 완전분리가 생김.
- 임대료는 읍면동 단위(17개 값), 매출은 상권×업종 평균이라 개별 점포 값이 아님.
- 팀 데이터셋의 경쟁 변수와 이 저장소의 값은 점포별로 일치하는 비율이 약 53~60%(업태 분류 기준 차이로 추정).
