# 서울시 성동구 음식점 폐업 위험 분석 — 경쟁 네트워크와 생존분석

공개 인허가 좌표만으로 점포별 **경쟁 네트워크**를 구축하고, 2021-04-01에 영업 중이던 성동구 음식점 3,775곳이 2026-09-12까지 폐업하는지를 추적하는 **생존분석(Cox)** 저장소입니다. 최종 목표는 추정한 위험비를 System Dynamics(SD) 모형의 폐업률로 연결해 3~5년 후 상권의 폐업률과 정책 시나리오를 비교하는 것입니다(SD 단계는 진행 중이며 이 저장소에는 포함되지 않음).

> **상태: 진행 중인 연구입니다.** 아래 분석 결과는 중간 결과이며 탐색적입니다.

## 연구 설계 한 줄 요약
- **분석 단위:** 점포 1개 (2021-04-01 영업 중 + 좌표 보유 3,775곳)
- **설계:** 기준일 한 시점의 스냅샷 + 이후 추적. 모든 설명 변수는 기준일 값이고 시계열은 쓰지 않음
- **결과 변수:** 기준일부터 폐업까지의 일수(`duration_days`)와 폐업 여부(`event`; 폐업 1,656곳 43.9%, 관측 종료까지 영업 2,119곳은 중도절단)
- **핵심 설명 변수:** 반경 내 동종 경쟁 수, 인접 음식점 수, 업종 다양성, 네트워크 구조 지표(군집계수 등); 통제 변수: 업력, 면적, 업종, 렌트

## 재현 방법
```bash
pip install -r requirements.txt
python scripts/99_make_manifest.py --verify   # raw/ 원자료가 변하지 않았는지 확인
python scripts/run_all.py                     # 전체 재현 (약 2분)
```
- 지오코딩은 `out/geocode_cache.jsonl`의 저장된 응답을 사용하므로 **외부 API 호출과 API 키가 필요 없습니다.** 캐시에 없는 주소를 새로 조회하려면 환경변수 `GEOCODE_API_KEY`(VWorld)를 설정하세요. 키는 코드·산출물 어디에도 저장되지 않습니다.
- **재현 검증(2026-10-08):** 이 저장소에서 처음부터 실행한 결과 9개 단계가 모두 성공했고, 이전 산출물 14개와 MD5가 전부 같았으며 최종 데이터셋 MD5가 원본 프로젝트와 일치했습니다.

## 중간 결과 (탐색적, 표준편차 1 증가당)
최종 데이터셋 3,767곳(면적 결측 8곳 제외), 반경 300m. Cox는 업종 층화, 로지스틱은 기준일 후 3년 내 폐업(27.8%).

| 변수 | Cox 위험비 | 로지스틱 승산비 | 비고 |
|---|---|---|---|
| 업력(log) | 0.75 | 0.72 | 동네 보정 후에도 유의 |
| 면적(log) | 0.88 | 0.83 | 동네 보정 후에도 유의 |
| 렌트(log) | 0.93 | 0.92 | 동네 보정 후 유의하지 않음 |
| 동종 경쟁 | 0.90 | 0.91 | 동네 보정 후 유의하지 않음 |
| 인접 음식점 수 | 0.91 | 0.89 | 동네 보정 후 유의하지 않음 |
| 군집계수 | 1.03 | 1.05 | 유의하지 않음 |

- 방법(Cox/로지스틱)을 바꿔도 방향은 대부분 같음. 예측 성능은 낮음(Cox concordance 0.611, 동네 단위 교차검증 AUC 0.614 — 업력만 쓴 모델 0.595).
- 클러스터가 16개뿐이라 동네 보정 p값은 불안정할 수 있음.

## 알려진 한계와 주의
- **생존자 코호트:** 기준일에 이미 영업 중이던 점포만 포함 (기준일 이전 폐업 8,695곳, 이후 개업 2,721곳 제외). 경쟁 변수는 기준일 한 시점 값.
- **리뷰 변수 사용 금지:** `has_review`는 폐업 점포에서 구조적으로 0%라 생존모형에 넣으면 완전분리가 생김(위험비 0, 성능 허상).
- **렌트는 읍면동 단위**(17개 값). 팀의 `rent_mean/median`은 2021년 1분기(603건) 집계로 사근동(2건)·송정동(4건)은 자료가 부족해, 분석에는 기준일 직전 12개월 중앙값 `rent_base`를 사용.
- **`area_category_sales_per_store_final`은 개별 점포 매출이 아니라** 상권×업종 2021Q1 점당 매출(표본 검증)이며, 미관측 321곳은 인근 상권 매출의 IDW 보간(팀 문서). 일부 점포는 상권 코드 없이 값이 있어 매핑 방식 확인 필요.
- 상권분석서비스 2025년 점포 파일은 컬럼명이 영문(`stdr_yyqu_cd` 등)이며 대부분의 CSV는 cp949 인코딩.
- **좌표계:** 인허가 좌표는 EPSG:5174(상권 SHP는 5181). 313m 차이를 변환으로 정합했으며 점포 간 거리는 변환으로 5mm 이하 변함.
- 팀 데이터셋의 구축 코드와 일부 변수 정의(리뷰·렌트·매출)는 팀 확인이 필요함(`docs/DATA_DICTIONARY.md` 참고).
