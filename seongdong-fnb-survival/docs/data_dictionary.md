# 최종 데이터셋 변수 사전 — `data/processed/final_dataset.csv`

**3,775행 × 54열.** 행 = 2021-04-01에 영업 중이던 성동구 일반음식점 1개. 모든 설명 변수는 **기준일 값**이며, 결과 변수는 기준일 이후 2026-09-12까지의 폐업 추적입니다.
출처 열의 **팀**은 팀원이 구축한 `data/raw/team_dataset.csv` 값을 그대로 보존한 것, **우리**는 본 저장소 코드가 계산한 값입니다.
